# Desvia — Dashboard de Gestão de Incidentes de TI

Dashboard de Business Intelligence desenvolvido em **Power BI** para monitoramento e análise de incidentes e operações de Tecnologia da Informação.

A solução centraliza informações operacionais e apresenta indicadores de **atendimento, resolução, SLA, reincidência e desempenho dos sistemas**.

O Desvia permite acompanhar os principais indicadores operacionais e analisar os incidentes por diferentes dimensões, como **prioridade, sistema afetado, responsável, localidade e tipo de ocorrência**.

## Indicadores

- Total de chamados
- TMA — Tempo Médio de Atendimento
- TMR — Tempo Médio de Resolução
- TMEF — Tempo Médio Entre Falhas
- SLA cumprido e violado
- Incidentes reincidentes

## Tecnologias

**Power BI · Power Query · DAX · Modelagem de Dados · Data Visualization**

## Dados

Base de dados fictícia desenvolvida para fins de demonstração e análise, contendo informações sobre incidentes, solicitações, problemas e mudanças.
